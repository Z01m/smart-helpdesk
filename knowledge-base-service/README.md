# Knowledge Base Service

**База инструкций и справочных материалов для пользователей и AI-помощника.**

Сервис хранит статьи и категории, позволяет находить материалы по текстовому запросу и предоставляет AI Worker поиск по смыслу. Именно эти статьи служат контекстом для ответов на обращения.

| Параметр | Значение по умолчанию |
|---|---|
| HTTP | `http://localhost:8083` |
| База данных | PostgreSQL с pgvector · `knowledge_base` |
| Зависимости | PostgreSQL/pgvector, Ollama |

## Что делает сервис

- Создаёт, возвращает, обновляет и удаляет статьи.
- Объединяет статьи в категории, поддерживает фильтрацию и постраничную выдачу.
- Выполняет полнотекстовый поиск с русским словарём PostgreSQL.
- Делит статьи на фрагменты и сохраняет их embeddings для поиска по смыслу.
- Возвращает AI Worker наиболее близкие к вопросу фрагменты с названиями статей и оценками сходства.
- Переиндексирует статью по запросу администратора.

## Как статья становится доступной для AI

Администратор передаёт заголовок, текст и необязательную категорию. Сервис делит текст на фрагменты примерно по 2000 символов с перекрытием 200 символов, чтобы сохранить контекст на границах. Затем Ollama преобразует фрагменты с заголовком в числовые векторы — **embeddings**.

Статья, фрагменты и векторы сохраняются одной транзакцией. При обновлении старые фрагменты заменяются новыми. Если Ollama недоступна, прежняя версия статьи остаётся сохранённой; конкурентное изменение статьи возвращает `409`.

## HTTP API

Для публичного API нужен JWT, выданный Gateway. Читать материалы могут авторизованные пользователи; создание, изменение, удаление и переиндексация доступны роли `ADMIN`.

| Метод | Адрес | Назначение |
|---|---|---|
| POST | `/api/v1/articles` | Создать статью, `201` |
| GET | `/api/v1/articles/{id}` | Получить статью |
| PUT | `/api/v1/articles/{id}` | Обновить статью и embeddings |
| DELETE | `/api/v1/articles/{id}` | Удалить статью и её фрагменты, `204` |
| POST | `/api/v1/articles/{id}/reindex` | Пересоздать embeddings |
| GET | `/api/v1/articles?query=пароль&category=UUID&page=0&size=10` | Поиск и список статей; параметры необязательны |
| GET | `/api/v1/categories` | Получить категории |
| POST | `/api/v1/categories` | Создать категорию |
| POST | `/internal/v1/knowledge/search` | Поиск фрагментов для RAG |

Тело создания и обновления статьи:

```json
{
  "title": "Как сбросить пароль",
  "content": "Откройте страницу входа и выберите восстановление пароля...",
  "categoryId": null
}
```

Для создания категории передаётся `{"name":"Аккаунт"}`.

## Внутренний поиск для RAG

Запрос защищён заголовком `X-Internal-Api-Key`. Он принимает либо текст вопроса, либо готовый embedding, а также `topK` — количество результатов от 1 до 50.

Пример поиска по тексту:

```json
{"query": "Как восстановить доступ к аккаунту?", "topK": 5}
```

AI Worker использует вариант с полями `embedding` (массив из 768 чисел) и `topK`. Ответ содержит массив `chunks`; каждый элемент включает `articleId`, `title`, `text` и `score`. При пустой базе возвращается пустой массив.

Поиск использует косинусное сходство векторов: более высокая оценка означает более близкий смысл. AI Worker сам выбирает порог релевантности и формирует контекст для генерации ответа.

## Конфигурация

| Переменная | Значение по умолчанию / назначение |
|---|---|
| `KNOWLEDGE_BASE_PORT` | `8083` |
| `KNOWLEDGE_BASE_DB_URL` | `jdbc:postgresql://localhost:5432/knowledge_base` |
| `KNOWLEDGE_BASE_DB_USERNAME` / `KNOWLEDGE_BASE_DB_PASSWORD` | Учётные данные БД |
| `AI_BASE_URL` | `http://localhost:11434` |
| `AI_EMBEDDING_MODEL` | `nomic-embed-text` |
| `INTERNAL_API_KEY` | Общий с Worker ключ внутренних запросов |
| `JWT_SECRET` | Общий с Gateway ключ JWT |

Текущая размерность embeddings — **768**. Модель и её версия должны совпадать с AI Worker. При смене embedding-модели статьи нужно переиндексировать; изменение размерности также требует миграции схемы БД.

## Запуск

Используй PostgreSQL с расширением pgvector из корневого Compose и работающую Ollama с моделью `nomic-embed-text`. Из корня репозитория:

```shell
mvn -pl knowledge-base-service -am package -DskipTests
java -jar knowledge-base-service/target/knowledge-base-service-1.0.0-SNAPSHOT.jar
```

Flyway создаёт таблицы и поисковые индексы при старте приложения.
