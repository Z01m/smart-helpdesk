# Common

**Общие контракты событий для сервисов Smart Helpdesk.**

Модуль содержит Java-типы сообщений, которыми сервисы обмениваются через Kafka. Благодаря общей библиотеке отправитель и получатель используют одинаковую структуру события и названия топиков.

Это библиотека Maven: она подключается как зависимость, отдельно не запускается, не имеет HTTP-порта и базы данных.

## Что находится внутри

| Тип | Назначение |
|---|---|
| `EventEnvelope<T>` | Обёртка сообщения: `eventId`, `eventType`, `occurredAt`, `correlationId` и `payload` |
| `TicketCreatedEvent` | Идентификаторы тикета и пользователя, текст обращения, уровень клиента и время создания |
| `TicketProcessedEvent` | Категория, приоритет, тональность, оценка релевантности, ответ, источники и признак участия оператора |
| `TicketStatusChangedEvent` | Предыдущий и новый статусы, автор и время изменения |
| `KafkaTopics` | Названия топиков проекта |

`eventId` позволяет получателю распознавать повторную доставку. `correlationId` связывает сообщения одного процесса обработки и помогает проследить путь обращения между сервисами. `payload` содержит данные конкретного события.

## Кто использует события

| Топик | Отправитель | Получатели |
|---|---|---|
| `ticket.created` | API Gateway | AI Worker |
| `ticket.processed` | AI Worker | API Gateway, Notification Service |
| `ticket.status-changed` | API Gateway | Notification Service |
| `ticket.dlq` | Обработчики ошибочных сообщений | Разбор сообщений, которые не удалось обработать |

Knowledge Base Service взаимодействует с AI Worker через отдельный HTTP-контракт поиска.

## Сборка

Common собирается вместе с остальными модулями. Для отдельной установки библиотеки в локальный Maven-репозиторий выполни из корня проекта:

```shell
mvn -pl common -am install -DskipTests
```

При изменении формата события нужно согласовать изменения отправителя и получателей: эти типы определяют контракт обмена между сервисами.
